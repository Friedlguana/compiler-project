Language grammar
program    → statement*
statement  → assignment | if_statement
assignment → ID = expression ;
if_stmt    → if ( condition ) { statement* }
             [ else { statement* } ]
condition  → expression relop expression
expression → term ((+ | -) term)*
term       → factor ((* | /) factor)*
factor     → ID | NUMBER | ( expression )
relop      → < | > | <= | >= | == | !=
